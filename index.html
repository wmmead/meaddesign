About This Project

In the summer of 2026 I began playing around with music production on the iPad inside a piece of host software called AUM. AUM allows you to plug in many different instruments and effects modules, and while it’s not a full digital audio workstation, like Logic or Cubasis, you can use it to mix different tracks and record them. I think it’s best to think of these recordings as sketches.

Meanwhile, this website used to house my portfolio website, which was terribly out of date and last spring was hacked (it was built in WordPress), so I took it down and this domain has been sitting fallow ever since.

I thought it would be fun to do something with the various pieces of tracks I’ve been making in AUM. The script is set to start playing a track, and when that track is 1/3 over, it starts playing another one, randomly. This way the audio mix is never quite the same. I used the Granim.js library to create the gradients and the Audiomotion library to make the audio visualizer. The animated text comes from GSAP and the splittext.js library.

I used Claude Code to do much of the coding, but the design and content are all mine. You can check out the code on GitHub.

— Bill Mead
